# Development Roadmap

Each release has a defined review gate. Work on the next version starts after the current version has been reviewed.

## v0.1.0 — Foundation

- [x] Modular Python project structure
- [x] Basic PySide6 application window and navigation
- [x] Versioned SQLite database
- [x] Excel import and source-preserving data model
- [x] Import validation report
- [x] Initial documentation and Windows build script

## v0.2.0 — Roadmap Engine

- [x] Rich roadmap detail view, categories, phases, and objectives
- [x] Progress editing and source-aware status handling
- [x] Search and filters
- [x] Timeline views by month, year, phase, and source sheet order

## v0.3.0 — Gamification

- [x] XP awards and level progression based on workbook progression
- [x] Progress calculations and reward history

## v0.4.0 — Quest System

- [x] Main, side, certification, lab, and project quests
- [x] Boss quest markers from explicit workbook milestone/capstone signals
- [x] Mission selection from incomplete source objectives with prerequisite-aware readiness

## v0.5.0 — Skill Tree

- [x] Skill branches based on workbook Track values, with target ages and specialization timeframes
- [x] Skill and specialization status, progress, source XP, and resource details
- [x] Explicit prerequisite resolution and locked/available state without inferred dependency edges

## v0.6.0 — Dashboard

- [ ] Player profile, current mission, next objectives, and skill overview
- [ ] Progress summaries driven by the SQLite database

## v0.7.0 — Certifications, Projects, and Labs

- [ ] Dedicated trackers, completion dates, notes, and evidence links

## v0.8.0 — Achievements

- [ ] Progress-based achievements and milestone notifications

## v0.9.0 — Analytics

- [ ] Progress trends, category views, activity history, and skill analysis

## v0.10.0 — Backup and Import/Export

- [ ] Excel export and progress-preserving re-import
- [ ] Backup, restore, data validation, and migrations

## v0.11.0 — UX and Visual Polish

- [ ] Accessibility, keyboard shortcuts, loading/empty states, and performance pass

## v0.12.0 — Release Candidate

- [ ] Full test and bug-fix pass
- [ ] PyInstaller and fresh-machine installation validation
- [ ] User guide, developer guide, and final documentation

## v1.0.0 — Public Release

- [ ] Stable Windows release and standalone executable
- [ ] GitHub release, contribution workflow, and issue templates
